# WHY WE NEED THIS (stable rationale)
A cluster outline is a visual guide to which cells belong to a group, especially when point color encodes another biological variable. The scientific problem is communicative, not an attempt to infer true biological borders. Users need high-quality outlines without learning computational geometry or tuning many parameters. A package only earns its place if it improves on established tools in visible reliability, ease of use, performance, or repeatability. If existing tools already solve this well, build a thin, valuable interface rather than a gratuitous new algorithm.
