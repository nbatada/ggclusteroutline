# Upstream source audit · 22 November 2026

The [inventory](inventory.csv) separates versions in the live CRAN source index from versions at the inspected upstream commits. It records commit dates, archive digests, declared licenses and whether the downloaded tree contains a populated tests/testthat directory. The [issue snapshot](issues.csv) keeps non-PR entries among the first ten open items returned per repository. GitHub's aggregate count includes PRs. Activity, open reports and the presence of tests are maintenance signals. This audit did not run upstream test suites or establish license compatibility for redistributed code.

| Layer or engine | What the inspected code does | Consequence for this project |
|---|---|---|
| ggforce mark hull · MIT | Transforms panel coordinates, converts the coordinates to millimetres in grid's makeContent, handles up to two unique points and special collinear cases, then invokes its own compiled concaveman implementation seeded by a convex hull. Default expansion is 5 mm. [Hull](https://github.com/thomasp85/ggforce/blob/128001400bee8ae1a27c772b6d9677660db01778/R/mark_hull.R) · [engine](https://github.com/thomasp85/ggforce/blob/128001400bee8ae1a27c772b6d9677660db01778/R/concaveman.R) | Existing one-layer solution for a mark around each group. Physical layout belongs in its cache key if storing the final path. |
| ggforce mark ellipse · MIT | Applies a Khachiyan enclosing ellipse to hull points, with tolerance, viewport conversion and sampled perimeter. [Source](https://github.com/thomasp85/ggforce/blob/128001400bee8ae1a27c772b6d9677660db01778/R/mark_ellipse.R) | Appropriate for a single oval mark. An ellipse cannot encode separated islands or an interior hole. An open [three-point orientation report](https://github.com/thomasp85/ggforce/issues/354) merits a fixture before reuse. |
| ggalt geom_encircle · MIT | Transforms the group, takes its convex hull, builds special spread shapes for one and two hull points, expands and draws an X-spline. An interpolating spline and positive padding change the relation to observed points. [Source](https://github.com/hrbrmstr/ggalt/blob/7b5e9f98d0afd8c47277e6e96ce152d63b8d3776/R/geom_encircle.r) | Available upstream development continued after CRAN archived the package in August 2025. A poor mandatory distribution dependency. [CRAN archive notice](https://cran.r-project.org/web/packages/ggalt/index.html) |
| ggdensity geom_hdr_lines · MIT | Computes a groupwise density on the supplied grid, defaults to MASS KDE, finds cutoffs for estimated probability mass and traces isolines. Defaults include four probability levels and a 100-by-100 grid. Axis ranges come from panel scales unless supplied. [Stat](https://github.com/jamesotto852/ggdensity/blob/cc94a18d5449bb9072bb9a83b65c8bdfa337810a/R/hdr.R) · [estimator](https://github.com/jamesotto852/ggdensity/blob/cc94a18d5449bb9072bb9a83b65c8bdfa337810a/R/method.R) · [cutoffs](https://github.com/jamesotto852/ggdensity/blob/cc94a18d5449bb9072bb9a83b65c8bdfa337810a/R/get_hdr.R) | Strong existing choice for a representative region. Domain, bandwidth, grid and contour level affect topology. Has numerical and visual tests. Open reports cover [equal HDRs](https://github.com/jamesotto852/ggdensity/issues/9) and [transformed axes in the function variant](https://github.com/jamesotto852/ggdensity/issues/10). These reports concern specific conditions. |
| ggpubr stat_chull · GPL ≥2 | Calls chull per group and returns the indexed rows. Default geom is path and the stat does not append the first vertex. Use geom="polygon", fill=NA for closed outlines. [Source](https://github.com/kassambara/ggpubr/blob/e46af48626049ece687e13ade833cc0ea43c9252/R/stat_chull.R) | Ready-made convex layer. Base grDevices implements the same geometry and returns unique hull indices, with finite inputs required. Our convex figures use base R. [R manual](https://stat.ethz.ch/R-manual/R-devel/library/grDevices/html/chull.html) |
| ggunchull stat_unchull · DESCRIPTION declares GPL3 | kNN-derived radius, DBSCAN, largest returned class, alpha-shape edges, offset, simplification, then smoothing. The separate stat_unchull0 uses sector quantiles. [Source](https://github.com/sajuukLyu/ggunchull/blob/282c549e4b27dc3a58d37e6dafb9e3f0a34de899/R/unchull.R) | Direct single-cell competitor. Its denoising step retained 135/135 points in the larger synthetic island and 0/15 in the smaller island, even though both carry the same label. Only this source function was exercised. [Counts](unchull-denoising.csv) · [export issue](https://github.com/sajuukLyu/ggunchull/issues/5) |
| ggplot2 geom_density_2d / extension API · MIT | MASS KDE followed by contours of density, normalized density or count. The base Stat splits by panel before group. The extension vignette already demonstrates a convex-hull stat. [Density layer](https://ggplot2.tidyverse.org/reference/geom_density_2d.html) · [Stat](https://github.com/tidyverse/ggplot2/blob/87a95d9103536296c8334e72f9f722855cd16bcb/R/stat-.R) · [extension guide](https://ggplot2.tidyverse.org/articles/extending-ggplot2.html) | Raw density heights require interpretation. A wrapper that adds only grouped hulls offers little value. Use documented extension points and test aesthetics and facet partitions. |
| concaveman R · GPL-3 | The matrix method initializes V8, loads the bundled JavaScript and transfers coordinates through JSON to return a single polygon. sf methods use the same matrix path. [Source](https://github.com/joelgombin/concaveman/blob/31d9b19055951ca06e52acd3eadd5bcba36bf680/R/concaveman.R) | Distinct implementation and dependency cost from the internal ggforce C++ path. [Precision report](https://github.com/joelgombin/concaveman/issues/13) and [enclosure report](https://github.com/joelgombin/concaveman/issues/17) motivate explicit containment tests. |
| sf st_concave_hull / GEOS · sf GPL-2 or MIT | sf passes ratio and allow_holes to GEOS. GEOS's concave hull is connected, except a degenerate point or line. Holes are optional. [sf source](https://github.com/r-spatial/sf/blob/973b74f7dd57818584ef1817847d9521810a9f97/R/geom-transformers.R) · [GEOS algorithm](https://libgeos.org/doxygen/classgeos_1_1algorithm_1_1hull_1_1ConcaveHull.html) | Useful existing general geometry engine. | alphahull ashape · GPL-2 or GPL-3 | Constructs an alpha shape from planar points using a scale parameter and Delaunay triangulation. At least three non-collinear points are required. [Package and manual](https://cran.r-project.org/package=alphahull) | Candidate when a user can justify a distance scale. Requires edge-to-ring and degenerate-case handling. No M0 speed or superiority claim. |
| isoband isolines/isobands · MIT | Traces lines or bands on supplied rectilinear grids via compiled routines. Output separates path IDs. [Source](https://github.com/r-lib/isoband/blob/35e6671cc2cde999d8e7ed468720473b4d00c839/R/isobands.R) | Useful backend after a field and threshold have been specified. The grid engine does not define population coverage or choose smoothing. |

## Recheck or replay

`collect.py SCRATCH --output OUTPUT` retrieves fresh public index and repository records. For the historical audit, use the SHAs in the inventory and the immutable source links above. No upstream implementation is vendored. To repeat the ggunchull diagnostic, put the pinned R/unchull.R under SCRATCH/ggunchull/R and run `Rscript research/sources/probe-unchull.R SCRATCH` after generating research/stress/points.csv (ggplot2, magrittr and dbscan required). The [name query](name-search.json) covers public GitHub repository names and the current CRAN index. The [archive check](name-archive.txt) searches historical CRAN directory names. These checks establish a dated search result and confer no reservation or trademark clearance. Recheck before any release.

For future distribution, prefer calling exported APIs and tracking their minimum supported versions. Inspect bundled third-party notices before any source reuse. A CRAN submission would need an independently worthwhile contribution, checks on supported platforms, documented examples and compatible dependency/license declarations.
