# Agent operating contract
Read NORTH_STAR.md, WHY_WE_NEED_THIS.md, CURRENT_STATE.md, ROADMAP.md, DECISIONS.md, specs/PRODUCT_SPEC.md, specs/ACCEPTANCE.md, and active ticket before any work.
Roles: Scientist (user) owns scientific/visual acceptance and release approval. CodexStrategy is accountable architect and reviewer. Implementer agents work bounded tickets. Independent reviewer checks evidence and regressions. Follow Scientist → Strategy → Ticket → Implementer → Evidence → Review.
M0 is AUDIT/STRATEGY ONLY. Do not implement package code until the scientist explicitly approves M0. CodexStrategy may research, inspect upstream source, run disposable benchmarks and produce comparative figures in research/; do not present speculative comparisons as measured.
For each ticket: define input, output, exclusions, tests, evidence, performance and stop criteria. Keep a decision log and CURRENT_STATE current. Never claim passing tests not executed. Do not publish, push public repos, submit CRAN, or change existing CellStyle without explicit authorization. Delegate bounded tasks, review independently, and commit verified changes locally.
Never confuse Leiden graph communities with boundaries in UMAP coordinates. Outlines are visual overlays, not biological ground truth. Preserve data and grouping, no reclustering. Prioritize correctness, ggplot compatibility, visual clarity, reproducibility, scalability and cache validity over algorithm novelty.
